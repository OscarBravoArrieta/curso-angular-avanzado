4. Prettier y ESLint sin conflictos en Angular
https://platzi.com/cursos/angular-avanzado/prettier-y-eslint-sin-conflictos-en-angu/

     Prettier se encarga de estabilizar o estandarizar el formato. Nos ayuda a establecer un solo formato de código para todo el proyecto.
     Prettier is an automatic code formatter. Its main function is to rewrite your source code according to predetermined and consistent rules.

     Para instalarlo: npm install prettier -D
     -D significa que es una dependencia que se usará solo en tiempo de desarrollo

     Se debe hacer la siguiente configuración:

          update packaje.json
            ...
            "scripts": {
                "format": "prettier --write ."
            }

        --write se utiliza para que haga automáticamente las correcciones, este modificador es similar al --fix del lint
        El punto(.) que se encuentra después del --write, indica todas las carpetas del proyecto

     Para automatizarlo: To format all project, execute: npm run format

     Al ejecutar este comando, el código se configura teneiendo en cuenta el estandar de buenas prácticas.

     En todo caso también se pueden implementar configuraciones persoanlidas, mediante el uso de un Configuration file. Para ello se crea en la raiz del proyecto el archivo: .prettierrc.json

     Ejemplo:

     Make a file .prettierrc.json
     {
         "tabWidth": 2,
         "useTabs": false,
         "singleQuote": true,
         "semi": true
     }

     Prittier y eslint, son proyectos aparte, por eso para que trabajen en armonía, se requiere hacer la siguiente instalación:
        
     npm install prettier-eslint eslint-config-prettier eslint-plugin-prettier -D

     update: eslint.config.js:
     const prettierRules = require("eslint-plugin-prettier/recommended");

     ¿Cuál es la diferencia entre ESLint y Prettier?
     Antes de sumergirnos en la implementación, es importante entender la distinción entre estas dos herramientas fundamentales:
     ESLint: Se enfoca en analizar la calidad del código, identificando malas prácticas y problemas de accesibilidad. No está diseñado principalmente para formatear código.
     Prettier: Es un formateador de código que establece un estilo consistente en todo el proyecto. Su objetivo es que todos los desarrolladores escriban código con el mismo formato, independientemente de sus preferencias personales.

    3. Ad the configuration
        "staging": {

                {
                "replace": "src/environments/environment.ts",
